# V1 · 看见数据

## 目标

把“设备里的值”稳定、可读地搬到界面上。先不碰 Modbus、数据库、控制。

## 新增概念

- 点位（TagDefinition）
- 工程值 = 原始值 × scale + offset
- 质量码（Good/Bad/Stale）
- 扫描周期
- 标签库（TagStore）
- UI 线程封送

## 运行

```powershell
scripts\run-v1.ps1
# 或
dotnet run --project demos/WinForms/Scada.WinForms.V1.SeeData -c Debug
dotnet run --project demos/Wpf/Scada.Wpf.V1.SeeData -c Debug
```

点“启动采集”，观察 8 张点位卡、表格、扫描次数、成功率、延迟、日志。

## 界面

- 顶部：运行状态、启动/停止、扫描周期（WinForms）。
- 卡片：液位/温度/压力带进度条，泵/加热/阀/自动带 ON/OFF。
- 表格：工程值、原始值、质量、更新时间。
- 右侧：采集统计 + 数据流示意 + 日志。

## 代码地图

| 文件 | 作用 |
|---|---|
| `src/Scada.Core/Tags/TagModels.cs` | 点位/质量/地址/报警配置 |

| `demos/WinForms/.../V1.../MainForm.cs` | WinForms 外壳 |
| `demos/Wpf/.../V1.../MainViewModel.cs` | WPF ViewModel + 定时刷新 |

## 关键流程

```text
定时器每 500ms
  → SimulatedDeviceSession.ReadAsync
  → 工艺模型编码成寄存器镜像
  → 按点位定义解码成工程值
  → TagStore.Update
  → UI 250ms 拉快照刷新卡片/表格
```

## 练习

1. 把周期改成 250ms / 1000ms，观察采集次数和延迟。
2. 新增一个“搅拌器”bool 点位（需要改工艺模型/寄存器映射）。
3. 给温度加一点噪声，观察趋势。
4. 把 `Scale` 改成 1，看液位变成 418 这种原始值。
