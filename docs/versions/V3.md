# V3 · 数据可信

## 目标

在真实采集上增加报警、历史、趋势，让数据“可信、可追溯”。

## 新增概念

- 四限报警 HH/H/L/LL
- 死区（恢复回差）
- 延时（持续超限才触发）
- 报警确认/恢复
- SQLite 历史/报警表
- 趋势图
- 故障注入

## 运行

```powershell
scripts\run-v3.ps1
```

1. 启动模拟 PLC → 连接并采集。
2. “报警”页点“注入超温故障”。
3. 约 2 秒后出现 HH 报警。
4. 点“确认选中报警”。
5. 等 20 秒故障恢复，报警清除。
6. “历史”页查询温度，导出 CSV。

## 界面

- 实时：点位表 + 液位/温度趋势 + 日志。
- 报警：横幅、活动报警、报警历史、确认、故障注入。
- 历史：点位/时间范围、查询、导出、清理。

## 数据流

```text
采集成功
  → TagStore.Update
  → AlarmEngine.Evaluate
  → 报警事件（UI + SQLite alarm_events）
  → SqliteHistoryStore.WriteTagRange（tag_history）
  → 趋势图 AddPoint
```

## 练习

1. 把温度 HH 改成 90、延时改 5 秒，观察报警出现时间。
2. 把死区改成 10°C，观察恢复变慢。
3. 查询 30 分钟历史，导出 CSV。
4. 用 DB Browser 看 `data/v3-history.db` 三张表。
5. 停掉模拟 PLC，确认 Bad 值不会误报警。
