# V5 · 系统联动

## 目标

把 SCADA 接到上位系统：REST 查询/写点、MQTT 遥测/报警/命令、ACK、断网补发。

## 新增概念

- REST API（Kestrel 内嵌）
- MQTT 发布/订阅（MQTTnet）
- 远程命令 + ACK
- Token 鉴权（演示）
- 离线缓存/补发
- 上位模拟器（内嵌 Broker）

## 运行

```powershell
scripts\run-v5.ps1
```

脚本会：

1. 启动上位模拟器（内嵌 MQTT Broker 18830）；
2. 启动 V5（模拟 PLC 15020 + REST 15080）；
3. 上位模拟器 3s/6s 下发 MQTT 命令，9s 调 REST；
4. 观察“北向”页发布数/待补发、控制页审计来源 Mqtt/Rest。

手动：

```powershell
dotnet run --project tools/Scada.UpperSystemMock -c Debug -- --auto --duration 8
dotnet run --project demos/WinForms/Scada.WinForms.V5.Northbound -c Debug
```

## 界面

- 实时 / 控制 / 北向 / 报警 / 历史 五个页签。
- 北向页：REST/MQTT 状态、已发布、待补发、错误、最近遥测 JSON、复制地址/主题。

## REST 示例

```bash
curl -H "X-Api-Key: scada-demo-token" http://127.0.0.1:15080/api/v1/tags

curl -X POST http://127.0.0.1:15080/api/v1/tags/tempSetpoint/write \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: scada-demo-token" \
  -d '{"value":75}'
```

## 断网补发演示

1. 运行 V5 + 上位模拟器。
2. 停掉上位模拟器（Broker 消失）。
3. V5 的“待补发”开始增加，`data/mqtt-outbox.jsonl` 增长。
4. 重新启动上位模拟器。
5. V5 自动重连并补发，待补发归零。

## 练习

1. 用 curl 读点位、写设定值、查历史。
2. 用 MQTT 客户端（MQTTX）订阅 `#`，看遥测/报警/ACK。
3. 改主题前缀，确保 V5 与上位模拟器一致。
4. 把 REST 改成只读（移除 POST），观察上位模拟器报错。
5. 把 Token 改错，观察 401 / ACK Rejected。
