# V2 · 连上设备

## 目标

把 V1 的“内存模拟”换成真正的 Modbus TCP，并让协议可见。

## 新增概念

- MBAP Header + PDU
- 功能码 01/03/05/06/16
- 寄存器地址（0 基 vs 4xxxx）
- 字节序（ABCD/DCBA/BADC/CDAB）
- 块读取（一次读连续地址，减少往返）
- 事务号、超时、异常码
- 指数退避重连

## 运行

```powershell
scripts\run-v2.ps1
```

V2 会自动启动内置模拟 PLC（15020）。也可以手动：

```powershell
scripts\run-plc-simulator.ps1
dotnet run --project demos/WinForms/Scada.WinForms.V2.Modbus -c Debug
```

## 界面

- 顶部：启动模拟 PLC / 停止模拟（断线）/ 连接并采集 / 断开。
- 卡片 + 点位表：工程值、原始值、质量。
- 右侧：Modbus 报文表（时间、方向、十六进制、解码）。
- 底部：运行日志。

## 演示

1. 启动模拟 PLC → 连接并采集。
2. 右侧出现 `FC=03 读寄存器 起始=0 数量=6`、`FC=01 读位`。
3. 点“停止模拟（断线）”：质量变 Bad/ERR，日志出现重连退避。
4. 再点“启动模拟 PLC”：10 秒内自动恢复 Good。

## 代码地图

| 文件 | 作用 |
|---|---|
| `src/Scada.Protocol/Modbus/ModbusPdu.cs` | PDU 编解码/异常 |
| `ModbusTcpClient.cs` | 事务号、超时、读写 API |
| `ModbusTcpSlave.cs` | MBAP/功能码/TCP 服务 |
| `ModbusTcpDeviceSession.cs` | 点位表 → 块读写 |
| `PlcSimulatorHost.cs` | 工艺模型 + 从站 |
| `src/Scada.Protocol/Modbus/ModbusFrame.cs` | 报文十六进制/解码 |
| `tools/Scada.PlcSimulator` | 独立模拟 PLC |

## 报文示例

```text
TX  00 01 00 00 00 06 01 03 00 00 00 06
RX  00 01 00 00 00 0F 01 03 0C ...
```

详见 [Modbus TCP 入门](../03-ModbusTCP入门.md)。

## 练习

1. 改 `byteOrder` 为 `DCBA`，看温度乱码，再改回。
2. 把 UnitId 改成 2，观察异常响应。
3. 用 Modbus Poll 连 15020，读 HR0 起 6 个寄存器。
4. 改 `scanIntervalMs=100`，看报文密度与 CPU。
