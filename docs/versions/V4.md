# V4 · 安全控制

## 目标

从“只看不控”变成“能安全地控”：联锁、写入、回读、审计、急停、自动模式。

## 新增概念

- 联锁（Interlock）
- 命令状态机
- 二次确认
- 回读比对 + 容差
- 命令审计
- 急停序列
- 自动模式（设备侧温控）

## 运行

```powershell
scripts\run-v4.ps1
```

1. 启动模拟 PLC → 连接并采集。
2. “控制”页：点“启泵”，确认，观察审计表出现 Succeeded + 回读值。
3. 等液位低于 10%（或注入低液位故障），再启泵 → 被拒绝。
4. 点“自动开” → 点“加热开” → 被联锁拒绝。
5. 点“写设定值” 75 → 成功。
6. 点“急停”，确认，观察四条命令顺序执行。

## 界面

- 实时 / 控制 / 报警 / 历史 四个页签。
- 控制页：手动/自动、设定值、急停、联锁矩阵、命令审计。
- 报警/历史页继承 V3。

## 命令链路

```text
确认 → 联锁 → 写入 → 等 300ms → 回读 → 比对 → 审计 → UI
```

拒绝/失败/超时都会产生审计记录。

## 联锁规则

- 启泵：液位 ≥ 10%
- 开加热：液位 ≥ 30%、温度 <95°C、非自动模式
- 自动：设定值 30–95°C、液位 ≥30%
- 设定值：30–95°C
- 急停：不检查联锁，按顺序停泵/加热/自动/关阀
