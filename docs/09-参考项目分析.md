## 1. NeoIndustrial（WinForms 数采平台）

### 看到了什么

- 单机 WinForms 形态：设备树、点位配置、Dashboard、报警、趋势、MQTT、数据库。
- 设备/点位模型：地址、类型、字节序、`y=kx+b`、修约、单位、HH/H/L/LL。
- 模拟器驱动：无硬件也能跑全链路。
- 设备线程 + 状态灯 + 断线重连 + 离线缓存。
- MQTT 双层主题（整包 + 逐变量）。
- SQLite 默认、零配置起步。

### 本项目怎么用

- 保留“一个点位一张卡 / 一张表”的信息密度；
- 保留四限报警 + 死区/延时的概念，但重写为可测试的独立 `AlarmEngine`；
- 保留“模拟器优先”的教学路径；
- 不照搬 39 种驱动、MCP、语义层、授权/登录。

### 明确没做

- 没有复制其 `Drivers/*.cs`、`Services/*.cs` 或 UI 代码；
- 没有引入 AGPL 代码；
- 没有实现其商业授权/激活逻辑。

## 2. twin-data-collector（MCP + 工业数采）

### 看到了什么

- 采集引擎 + MQTT + 多数据库 + REST/MCP 的数据出口分层。
- CSV 变量模板、模拟器、四色报警、MQTT JSON 包格式。
- “先把数据采上来，再谈 AI/数字孪生”的工程顺序。

### 本项目怎么用

- 北向数据出口拆成 `REST` + `MQTT` 两个适配器；
- 遥测 JSON 保留 `timestamp/device/values` 的思路；
- 保留模拟器零硬件演示。

### 明确没做

- 没有 MCP/AI 工具、40 协议、登录/授权；
- 没有复制任何驱动或服务代码。

## 3. iotgateway（.NET 10 B/S 工业网关）

### 看到了什么

- 南向采集/写入、北向 MQTT/ThingsBoard、RPC 反向控制。
- 内置 MQTT 服务、OPC UA 服务、Modbus Slave 模拟设备的演示方式。
- 驱动可扩展、变量表达式、变化上传/定时归档。

### 本项目怎么用

- 上位模拟器内嵌 MQTT Broker，做到“零安装”一键演示；
- 远程命令 → 联锁 → 写设备 → ACK 的双向链路；
- 模拟 PLC 作为独立进程/内嵌宿主两种形态。

### 明确没做

- 没有 B/S 架构、WTM 框架、插件市场；
- 没有 OPC UA/S7 等协议；
- 没有复制其代码。

## 4. 许可证结论

- `NeoIndustrial` 是 AGPL-3.0：即使只改一点，网络提供服务也可能触发源码开放义务。本项目**不复制、不派生**。
- `twin-data-collector` 的 README 与 GitHub 元数据许可证标识不完全一致，按更保守方式处理：只读研究，不复制。
- `iotgateway` 是 MIT，允许复用，但本项目仍选择原创实现，保持教学一致性。

第三方依赖：MQTTnet（MIT）、Microsoft.Data.Sqlite（MIT）、.NET（MIT）。见 `THIRD_PARTY_NOTICES.md`。
